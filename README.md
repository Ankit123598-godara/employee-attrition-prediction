# Employee Attrition Prediction — Jupyter Notebook Project

This project includes the notebook and dataset needed to run the employee attrition ML workflow.

## Files
- `Employee_Attrition_Prediction.ipynb` — complete project, with numbered steps and code cells.
- `data/Palo_Alto_Networks_Attrition.csv` — dataset included with the project (1,470 rows, 31 columns).
- `requirements.txt` — Python libraries.
- `outputs/` — generated results appear here after running the notebook.

## Run it in Jupyter (Windows)
1. Download the ZIP and choose **Extract All**.
2. Open Command Prompt or VS Code terminal.
3. Change directory to the extracted project folder. Example (adjust if you extracted elsewhere):
   `cd %USERPROFILE%\Downloads\Palo_Alto_Employee_Attrition_Jupyter_Project`
4. Create a virtual environment (recommended): `python -m venv .venv`
5. Activate it in PowerShell: `.venv\Scripts\Activate.ps1`
6. Install dependencies: `python -m pip install -r requirements.txt`
7. Start Jupyter: `python -m notebook`
8. In the browser, open `Employee_Attrition_Prediction.ipynb`.
9. Choose the Python kernel associated with this environment if prompted.
10. Run the notebook cells from the top, in order, using **Shift+Enter**. The first cell installs dependencies too; if you already installed them, it can be skipped.

## If `python` is not recognized
Try `py --version`. If that works, replace `python` with `py` in the commands.

## If the dataset cannot be found
Keep the notebook and the `data` folder in the extracted project folder. Open Jupyter from that project folder. The notebook also searches a few common nearby locations automatically.

## Main steps inside the notebook
1. Install libraries
2. Import libraries and set project paths
3. Load dataset
4. Inspect data quality and target balance
5. Explore data with charts
6. Create engineered features
7. Define predictors and target
8. Train/test split
9. Build preprocessing pipelines
10. Train and compare Logistic Regression, Random Forest, and Gradient Boosting
11. Evaluate the selected model
12. Generate employee risk scores
13. Summarize risk by department and role
14. Add simple heuristic reason codes
15. Review an individual employee profile
16. Save model, metrics, and employee scores
17. Review the final checklist

## Output files
After successful execution, `outputs/` contains a trained model, model comparison metrics, employee risk scores, and a project summary.

## Important note
The generated `Employee_ID` is a technical row identifier only; the source dataset does not contain a real employee ID. Risk scores are model predictions and must not be treated as proof that a person will resign or used as the sole basis for employment decisions.

## Optional Streamlit dashboard

1. Run all cells in `Employee_Attrition_Prediction.ipynb` in order, including the final cell that saves files in `outputs/`.
2. Open a terminal in this project folder and install requirements if needed:
   `python -m pip install -r requirements.txt`
3. Start the dashboard:
   `python -m streamlit run app.py`
4. Open the local URL printed in the terminal (usually `http://localhost:8501`).

The dashboard reads `outputs/employee_risk_scores.csv`, `outputs/model_comparison_metrics.csv`, and `outputs/project_summary.json`, which are generated by the notebook. If these files do not exist yet, run the notebook first.
